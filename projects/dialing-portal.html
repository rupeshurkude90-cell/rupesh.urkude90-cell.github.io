TECHNICAL PORTFOLIO · PROJECT CASE STUDY

Dialing Information Portal

Google Apps Script • Google Sheets • Google Calendar Web Intents

Project Overview

The Dialing Information Portal is a self-service web application built on Google Workspace that centralizes enterprise video conference room inventory from a master Google Sheet. Its primary purpose is to let employees and room administrators quickly search global meeting rooms and generate standardized joining instructions and Google Calendar invites.

Business Problem

Previously, video conference room credentials—such as Virtual Room IDs, PIN codes, external SIP/CRC addresses, and web join links—were stored inside a large multi-regional spreadsheet containing over thousands of rows. Users and administrators had to manually search raw spreadsheet rows, piece together four different connection options per room, and risk accidental edits to protected technical columns.

Solution Implemented

I implemented a serverless two-tier web application using Google Apps Script (Code.gs) as the backend data layer and a responsive single-page HTML/JavaScript frontend (Index.html). The backend reads and normalizes rows starting from Row 3 of the master Google Sheet, applies multi-attribute server-side filtering, and delivers structured JSON objects to the browser for dynamic rendering and one-click invitation actions.

Key Features

  • Multi-Attribute Real-Time Search: Filters rooms simultaneously across Region, Country, Site Name/City, Calendar Resource Name, and Room Name using case-insensitive substring matching and a 300ms input debounce.
  • Standardized 4-Mode Dialing Guide: Automatically formats each room's credentials into four joining methods: Internal Video Device, Web Browser URL, External Video Device (<RoomID>@zoomcrc.com), and Phone Dial-in.
  • One-Click Clipboard Copy: Copies clean, multi-line invitation text to the clipboard using the Browser Clipboard API backed by an in-memory JavaScript store (window._inviteStore) to avoid HTML escaping issues.
  • Direct Google Calendar Invite Generator: Prompts administrators for comma-separated guest email addresses and opens a pre-populated Google Calendar event template containing the meeting title, room location, guests, and full dialing instructions.
  • Input Validation & Resilient Sheet Parsing: Enforces alphabetic-only regex validation on Region and Country inputs while skipping Row 1 administrative banners, Row 2 headers, and blank rows via .getDisplayValues().

Technology Stack

  • Google Apps Script (V8 Runtime): Hosts the serverless Web App entrypoint (doGet) and executes server-side search and transformation logic (getRoomData).
  • Google Sheets & SpreadsheetApp API: Serves as the centralized room inventory database and provides string-normalized cell extraction via .getDisplayValues().
  • Browser Clipboard API & Google Calendar Web Intents: Automates one-click invitation copying (navigator.clipboard.writeText) and launches pre-filled calendar event drafts (calendar.google.com/calendar/render?action=TEMPLATE).

My Role & Contribution

I personally led the requirement analysis, solution architecture, iterative full-stack development (using AI assistance for rapid code generation and refactoring), live data testing, and Web App deployment. I also diagnosed and resolved production issues—including column-index shifts, Row 2 header leakage, and RPC serialization hangs—by refining row offsets, fallback PIN logic, and client-side error handlers.

Workflow

  • 1. Portal Initialization: The user opens the Web App URL, triggering doGet() to render Index.html and load the initial room directory via google.script.run.
  • 2. Data Extraction & Normalization: Code.gs reads Row 3 onward across Columns A–L using .getDisplayValues(), skips empty rows, and maps columns into structured JSON objects with fallback PIN resolution.
  • 3. Live Search & Filtering: As the user types into any of the five filter inputs, client-side regex sanitization and a 300ms debounce trigger server-side substring filtering.
  • 4. Dynamic Rendering: Matching rooms render into a responsive table showing Region, Country & City, Room & Calendar Name, and 4-option dialing instructions.
  • 5. Invitation Distribution: The user clicks 'Copy invite' to copy formatted details to the clipboard or 'Calendar Invite' to enter guest emails and open a pre-filled Google Calendar event.

Business Benefits

  • The portal eliminated manual transcription of room IDs, PINs, SIP strings, and web links while enabling fast multi-field room discovery across 750+ global records. It also simplified meeting scheduling for room administrators through one-click Google Calendar invites and protected the master spreadsheet from accidental user edits via a read-only web interface.
